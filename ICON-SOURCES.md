# Icon sources

Development and Photoshop logos: Devicon, https://github.com/devicons/devicon (MIT; brand marks remain their owners’ trademarks).
Microsoft Office icons: vscode-icons, https://github.com/vscode-icons/vscode-icons (MIT; Microsoft marks remain Microsoft trademarks).
MS Paint uses a palette symbol; AI tools and PC support use generic symbols because these entries describe categories rather than a single named application.
Icons are stored locally in assets/icons. No vendor endorsement is implied.

Contact section Viber and WeChat logos: Simple Icons, https://github.com/simple-icons/simple-icons (CC0). Email, phone and location icons are inline SVG interface symbols. Carrier names remain text labels.
