# Hobby icon assets

Manga and manhwa icons were generated with the built-in image-generation tool, then reduced to 128px PNGs for web performance while preserving transparency. Original copies remain in the local workspace as manga-source.png and manhwa-source.png.

## Final prompts

Manga: Use case: stylized-concept. Asset type: compact website hobby icon. Create one polished manga reading icon: an open black-and-white comic book with two or three clean panels, a small original anime-style face silhouette in one panel and clear speech bubbles, no readable text. Flat illustration with crisp dark charcoal outlines, ivory pages, restrained olive green binding. Centered square composition with generous transparent padding. Designed to remain recognizable at 48 pixels. No existing franchise characters, no words, no watermark, no extra objects. Transparent background.

Manhwa: Use case: stylized-concept. Asset type: compact website hobby icon matching an olive-green professional portfolio. Create one polished manhwa/webtoon reading icon: an upright phone or tablet displaying three vertically stacked colorful comic panels, a small original illustrated character silhouette and a speech bubble with no words. Flat illustration with crisp charcoal outlines, muted sage, warm coral and cream accents. Centered square composition with generous transparent padding. Recognizable at 48 pixels. No existing franchise characters, no text, no watermark, no extra objects. Transparent background.
